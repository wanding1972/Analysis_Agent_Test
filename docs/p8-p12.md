# P8–P12 implementation

P8 Drift compares two version-neutral execution records on capability, semantic,
plan, evidence, and answer surfaces. Differences are `regression` unless an
explicit path appears in `config/drift_rules.yml`; context mismatches are
`blocked`.

P9 Review keeps QA classification human-owned. A drift without a decision is
`pending`; a supplied decision is one of `BUG`, `EXPECTED_CHANGE`,
`DATA_ISSUE`, `BASELINE_ERROR`, `TEST_RULE_ERROR`, or `BLOCKED`.

P10 Reporting builds a stable summary and exports JSON, CSV, HTML, or XLSX.
P11 Application exposes orchestration for execution, version comparison,
review, and report export. It contains no domain thresholds or SDK calls.
P12 Presentation renders report JSON/HTML from the application report view;
it does not implement business rules or access infrastructure directly.
